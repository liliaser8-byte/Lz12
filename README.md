### Код 

```cpp
	private: System::Void button1_Click(System::Object^ sender, System::EventArgs^ e) {
		// Створюємо лінійний двозв'язний список цілих чисел
		std::list<int> myList = { 12, -5, 7, 0, -14, 3, -2 };

		// Виведення початкового списку у listBox1
		listBox1->Items->Clear();
		for (int x : myList) {
			listBox1->Items->Add(x.ToString());
		}

		// 1. Вставляємо число 25 ПЕРЕД кожним елементом з додатним значенням (x > 0)
		for (auto it = myList.begin(); it != myList.end(); ++it) {
			if (*it > 0) {
				myList.insert(it, 25); // insert автоматично вставляє елемент ПЕРЕД поточним ітератором it
			}
		}

		// Виведення проміжного результату у listBox2
		listBox2->Items->Clear();
		for (int x : myList) {
			listBox2->Items->Add(x.ToString());
		}

		// 2. Вилучаємо зі списку всі від'ємні числа (x < 0)
		for (auto it = myList.begin(); it != myList.end(); ) {
			if (*it < 0) {
				it = myList.erase(it); // видаляємо елемент і отримуємо ітератор на наступний
			}
			else {
				++it; // якщо число невід'ємне, переходимо до наступного елемента
			}
		}

		// Виведення кінцевого результату у listBox3
		listBox3->Items->Clear();
		for (int x : myList) {
			listBox3->Items->Add(x.ToString());
		}
	}
};
}

```

**Опис програми**

Програма являє собою віконний застосунок **Windows Forms (C++/CLI)**, який демонструє створення та модифікацію лінійного двозв'язного списку цілих чисел за допомогою стандартного контейнера `std::list<int>`. Інтерфейс складається з кнопки запуску обчислень та трьох списків `ListBox`, що відображають дані на кожному етапі обробки.

**Принцип роботи програми (покроково після натискання кнопки «Обчислити»):**

1. **Ініціалізація та виведення оригіналу:** усередині обробника події `button1_Click` створюється локальний список `std::list<int>` із заданими цілими числами (`12, -5, 7, 0, -14, 3, -2`), і його елементи виводяться у перший компонент `listBox1`.
2. **Вставка числа 25 перед додатними елементами:** програма проходить по списку ітератором від початку до кінця. Якщо поточний елемент строго більший за нуль (`*it > 0`), метод `insert(it, 25)` вставляє число `25` безпосередньо перед ним. Проміжний результат відображається у `listBox2`.
3. **Вилучення від'ємних чисел:** відбувається повторний прохід уже зміненим списком. Для кожного елемента, меншого за нуль (`*it < 0`), викликається метод `it = myList.erase(it)`, який видаляє поточний вузол і повертає дійсний ітератор на наступний елемент (якщо число невід'ємне, ітератор просто зсувається далі через `++it`).
4. **Виведення фінального результату:** остаточний список без від'ємних чисел виводиться у третій компонент `listBox3`.

**Висновок**

У ході виконання лабораторної роботи № 12 я набула практичних навичок створення, обходу, модифікації та візуалізації лінійного двозв’язного списку цілих чисел за допомогою стандартного контейнера `std::list` у середовищі Visual Studio (C++/CLI Windows Forms).

Згідно із завданням варіанта № 13 було розроблено програму, яка виконує вставку числа `25` перед кожним додатним елементом списку методом `insert()` та вилучає всі від’ємні числа методом `erase()`. Під час реалізації алгоритму було враховано ключові особливості роботи з ітераторами контейнера `std::list`: вставка елемента не порушує дійсності поточних ітераторів, тоді як видалення робить ітератор на вилучений вузол недійсним, тому для коректного продовження циклу використано присвоєння `it = myList.erase(it)`. Також враховано специфіку керованого коду C++/CLI, через яку нативний контейнер `std::list` оголошено локально всередині обробника події кнопки.

Результати роботи програми на кожному етапі перетворення списку наочно відображено в елементах керування `ListBox` та перевірено на тестовому наборі даних. Поставлену мету досягнуто, отримані результати повністю відповідають умові завдання.
